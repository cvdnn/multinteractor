# multinteractor 跨机协同客户端界面设计规范 (UI/UX Specification)

## 1. 设计概述与设计哲学

**multinteractor** 是一套面向个人多设备（macOS / Windows / Linux）无缝协同的高性能数据流转系统。客户端界面专注系统自身的四大核心业务：**集群设备拓扑与连接感知**、**跨设备多模态剪贴板流**、**大文件/目录边传边下任务中枢**以及**远程文件目录树浏览与安全台账**。

### 1.1 设计风格：浅系现代化桌面（Light Clean Aesthetic）
* **视觉基调**：轻量、通透、清晰、低噪。采用 Slate-50/White 极简分层体系，杜绝大面积刺眼暗色与厚重质感。
* **信息密度**：8px 网格对齐规范，卡片化分组，主次分明，状态徽章清晰，重要安全策略（BLAKE3 校验、跨机秒传关闭、Token 轮转）一目了然。
* **交互反馈**：微动效交互（150ms 微过渡、Pulse 呼吸绿点、轻量 Toast 悬浮通知），不干扰日常办公心流。

## 2. 界面总体信息架构 (Information Architecture)

客户端采用**响应式双栏工作台 + 浮动模态窗**布局结构：

```text
+----------------------------------------------------------------------------------------------------+
|  [顶部全局状态与网络拓扑指标栏 (Top KPI & Network Status Strip)]                                   |
|  - 本机节点与角色  |  - 云端 TLS 中继通道 (RTT)  |  - 局域网 P2P (空闲倒计)  |  - BLAKE3 / 秒传策略 |
+---------------------------------------------------+------------------------------------------------+
|  【左栏】集群设备网络与全局自动化控制 (5 Cols)     |  【右栏】传输任务中枢与剪贴板流 (7 Cols)       |
|                                                   |                                                |
|  1. 集群设备拓扑网格 (Device Cluster Mesh)        |  1. 正在进行的多任务传输中枢 (Active Transfers)|
|     - 本机节点状态卡片 (macOS / Local)            |     - 边传边下模式 (Stream Teeing) 动态指示器  |
|     - Windows 节点 (LAN 直连可用 / 快速同步 / 浏览)|     - 4MB 分块落盘进度条与当前传输速度 (MB/s)  |
|     - Linux 节点 (外网中继通道 / 快速同步 / 浏览) |     - 实时已校验分块徽章与暂停/取消控制        |
|                                                   |                                                |
|  2. 全局快捷热键与自动化配置                      |  2. 跨设备多模态剪贴板流 (Clipboard Stream)    |
|     - Alt+C 跨机复制 (文本/图片/文件夹)           |     - 文本卡片 (内联摘要、一键复制到剪贴板)    |
|     - Alt+V 智能粘贴 (哈希校验并智能落盘)         |     - 图片卡片 (高清缩略图预览、另存为)        |
|     - Alt+S 唤出目标远程目录选择面板              |     - 单文件/嵌套文件夹归档包 (落盘路径、Finder)|
|                                                   |     - 作用域指示 (广播 BROADCAST / 定向 DIRECT)|
|                                                   |                                                |
|  3. 底部安全运维入口 (Token 轮转 / 设备台账治理)  |                                                |
+---------------------------------------------------+------------------------------------------------+
```

### 3.2 远程目录选择与定向同步模态窗 (Remote Directory Picker Modal)

用户通过右键菜单 `【同步到... >】` 或快捷键 `Alt+S` 唤出的远程文件浏览与目标落位对话框：

```text

|  浏览并同步到目标机器目录: Windows-Workstation           [X] 关闭      |
+------------------------------------------------------------------------+
|  目标路径: D:\工作目录\2026_AI资料                     可用: 256.4 GB  |
+------------------------------------------------------------------------+
|  目录结构 (500ms 超时保护单层懒加载):                                  |
|  ▼ 💾 系统盘 (C:)                                                      |
|  ▼ 📁 数据盘 (D:)                                                      |
|    ▼ 📂 工作目录                                                       |
|      ▶ 📂 2026_AI资料 (当前已选中)                                     |
|      ▶ 📂 模型权重备份                                                 |
|      ▶ 📂 临时归档                                                     |
|    ▶ 📂 个人软件                                                       |
|  ▶ 🖥️ 用户桌面 (Desktop)                                               |
|  ▶ 📥 下载目录 (Downloads)                                             |
+------------------------------------------------------------------------+
|  [ + 新建远程文件夹 ]                         [ 取消 ]  [ 确定同步到此 ]|
+------------------------------------------------------------------------+
```

#### 关键交互点：
1. **盘符与常用目录探测**：自动枚举 Windows 盘符（`C:\`、`D:\`）及用户家目录快捷入口（Desktop、Downloads、Documents）。
2. **500ms 单层懒加载防假死**：远程目录扫描设置 500ms 保护超时间隔，超时跳过未就绪网络驱动器，防止界面挂起。
3. **安全路径拦截**：在输入或展开时，严格通过 `validate_rpc_path` 拦截包含 `..` 的路径穿越与 `/etc`、`C:\Windows` 等系统敏感目录。

## 4. 前端组件划分与实现规范 (Frontend Implementation)

客户端前端基于 **Tauri + TypeScript + Tailwind CSS** 构建：

### 4.1 组件层级映射
* `App.vue / App.tsx`：根布局容器，维护全局浅色主题与视口自适应；
  * `TopStatusBar`：渲染 4 组关键状态卡片（本机、云端 TLS、LAN 通道、安全策略）；
  * `DeviceClusterMesh`：渲染设备卡片列表，支持点击“浏览目录”或“定向同步”；
  * `ActiveTransferHub`：监听 `mi-daemon` 上报的实时分块落盘水位线，绘制动态进度条；
  * `ClipboardTimeline`：展示文本/图片/归档流，提供一键写入本地剪贴板与落盘交互；
  * `RemoteDirectoryPickerModal`：处理远程驱动器展开、目录懒加载、新建文件夹与同步确认；
  * `SecurityLedgerPanel`：处理 Token 复制、密钥轮转确认对话框、设备状态切换（踢出/禁用/删除）。

### 4.2 状态驱动与 IPC 契约
* **守护进程通信**：UI 进程通过本地回环 IPC (`127.0.0.1:53318`) 调用 `mi-daemon` 接口；
* **事件推流**：`mi-daemon` 通过 IPC 实时推送接收事件帧 `CloudEventEnvelope (v6)`，前端响应式追加到剪贴板时间轴中。
